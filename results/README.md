# results/

Everything in this folder was generated by real runs of the pipeline. Nothing here is hand-written except this file.
The three headline deliverables sit at the top level. Supporting files are grouped by the stage that produced them.

```
results/
├── comparison.csv              test metrics + efficiency for A and B         (src/evaluate.py)
├── confusion_matrix.png        best experiment (B) on the test set           (src/evaluate.py)
├── training_curves.png         train/val loss + val Macro F1 per epoch        (src/evaluate.py)
│
├── eda/                                                                       (src/eda.py)
│   ├── class_distribution.png       label share per split
│   ├── token_length_distribution.png
│   └── eda_summary.json             quality checks, token stats, label counts
│
├── training/                                                                  (src/train.py)
│   ├── A_feature_extraction_history.json   per-epoch metrics, timing, param counts
│   └── B_partial_finetuning_history.json
│
├── evaluation/                                                                (src/evaluate.py)
│   ├── classification_report_A_feature_extraction.txt   per-class precision/recall/F1
│   ├── classification_report_B_partial_finetuning.txt
│   └── misclassified_examples.csv   all 233 test errors of B, most confident first
│
└── logs/                       console output of each run (shell-redirected)
    ├── eda_log.txt
    ├── train_log.txt
    └── evaluate_log.txt
```

Pipeline order: `eda/` → `training/` → `evaluation/` + top-level files. To regenerate everything, run
`python -m src.eda`, then `python -m src.train`, then `python -m src.evaluate` from the repository root.
